description: Add or improve documentation across the codebase.
---

Objective: Enhance code clarity and maintainability by adding or improving documentation without altering functional behavior.

1. **Scope Identification**:
   - Identify files lacking documentation or with outdated/unclear comments.
   - Include docstrings, inline comments, and README files where appropriate.

2. **Quality Standards**:
   - Focus on clarity, completeness, and relevant examples.
   - Ensure documentation follows the project's established style (e.g., PHPDoc for PHP).

3. **Constraints**:
   - Do NOT change any functional code.
   - Avoid redundant comments that simply restate obvious code.
