# Objective: Knowledge Retention
Enhance system maintainability by capturing the *intent* and *logic* behind the code.

1. **The "Why" Principle**:
   - Focus documentation on explaining *decisions* and *context*. Avoid "stuttering" comments (comments that simply repeat what the code says).
   - Document business rules and complex algorithms that aren't self-evident from the code.

2. **Structural Standards**:
   - Follow language-specific documentation standards (e.g., PHPDoc for PHP, JSDoc for JS/TS). Ensure type and parameter accuracy.
   - Update READMEs to reflect architectural changes or new infrastructure requirements.

3. **Maintenance**:
   - Identify and prune stale comments that no longer match the implementation.
   - Verify that links and file references in documentation are valid.
